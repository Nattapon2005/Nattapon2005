## 👋 Hey there, I'm Nut

I'm a **Full-Stack Web Developer** based in Bangkok who loves turning ideas into **clean, responsive, and high-performing web products**. I care deeply about both sides of the craft — how an interface *feels* in the browser and how reliably the system *runs* behind the scenes.

- 🔭 **What I build:** Full-stack web platforms, interactive 3D/motion experiences, and RESTful APIs
- ⚡ **Core focus:** `Next.js` · `React` · `TypeScript` · `Node.js` · `Express` · `PHP` · `SQL` · `Docker`
- 🌱 **Currently exploring:** Cloud-native architectures, Prisma ORM, PostgreSQL, and AI-powered workflows
- 🤝 **Open to:** Software engineering roles, freelance web development, and creative collaborations
